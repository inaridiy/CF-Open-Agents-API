# Agent Builder

A small [CF-Open-Agents-API](https://github.com/inaridiy/CF-Open-Agents-API) app: type a prompt, an agent builds the result in a sandbox, the page shows the transcript as it happens, and the files it wrote under `/workspace/outputs` come back as a zip, or one download per file when they are too large for a Worker to zip.

| File            | Role                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/agents.ts` | The `defineAgentWorker` composition: presets, the model gateway and authentication. Change models and presets here                                                                                                                                                                                                                                                                                                          |
| `src/index.tsx` | The Hono app. It talks to this Worker's own `Agents` entrypoint through the `AGENTS` Service Binding with the official `openai` client, whose `fetch` is `tenantFetch(env.AGENTS, "default")`: no token crosses the binding. `Transcript` is one fold over the session's event log and the only source of a transcript: the settled page, the committed head of a running page and the live stream are all the same reducer |
| `src/ui.tsx`    | `hono/jsx` views. Settled jobs are one page; a running job is the same page streamed: the committed transcript first, then a fragment per event, no client script                                                                                                                                                                                                                                                           |

| Route                           | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /`                         | The prompt form; presets come from `GET /cf/v1/capabilities`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `POST /jobs`                    | `sessions.create({ agent, environment: { type: "openai_hosted" }, input })`, then redirects to the job page. The subagents checkbox, off by default, enables `multi_agent` so the preset may `cf_delegate` to its `delegates`                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `GET /jobs/:id`                 | The job page. While the turn runs it opens the live SSE (`sessions.events.stream`), replays the durable log (`GET /cf/v1/sessions/:id/events?after=<seq>`) into the committed transcript, writes that, then keeps the response open and appends each later event as HTML: text deltas stream into the open block, every `item.done` is an item view, and the artifacts and the download close the page when the session settles. A reload mid-turn repeats the replay and reattaches; nothing is lost. Once settled (`idle`, `failed`, or `requires_action`, which this demo cannot answer because it declares no function tools) the same replay, read to the end of the log, is one complete page |
| `GET /jobs/:id/zip`             | Every `sessions.artifacts` entry, zipped, while they total at most 32 MiB: `zipSync` holds all of them and the archive in a Worker's 128 MB at once (roughly twice the limit at peak), and the API allows far more per turn                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `GET /jobs/:id/files/:artifact` | One artifact, streamed straight through with nothing buffered. Past the zip cap the job page links each file here instead of offering the zip                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

## Run

The commands use pnpm; npm, yarn and bun work the same way with their own `install`, `exec` and `dlx` forms.

```sh
pnpm install
pnpm exec wrangler login   # Workers AI and deployments need your account
pnpm dev                   # Docker must be running; the first image build takes several minutes
```

Open <http://localhost:8787>. The app reaches the API over its Service Binding and names the tenant itself, so `API_TOKEN` in `.dev.vars` (32+ characters) only guards the HTTP API for outside callers. With rootless Docker use `pnpm dev:rootless` if `create-cf-open-agents-api init` added it.

Production: `pnpm dlx create-cf-open-agents-api@alpha setup` creates the R2 buckets and puts the secrets, then `pnpm exec wrangler deploy`.
