# Agent Builder

A small [CF-Open-Agents-API](https://github.com/inaridiy/CF-Open-Agents-API) app: type a prompt, an agent builds the result in a sandbox, the page shows the transcript as it happens, and the files it wrote under `/workspace/outputs` come back as a zip.

| File            | Role                                                                                                                                                                                                                                                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/agents.ts` | The `defineAgentWorker` composition: presets, the model gateway and authentication. Change models and presets here                                                                                                                                                                                                                 |
| `src/index.tsx` | The Hono app. It talks to this Worker's own `Agents` entrypoint through the `AGENTS` Service Binding with the official `openai` client, whose `fetch` is `AGENTS.fetchAs(tenant, request)`: no token crosses the binding. `Transcript` is one fold over the session's event log, used for the replay and for the live stream alike |
| `src/ui.tsx`    | `hono/jsx` views. Settled jobs are one page; a running job is the same page streamed: the committed transcript first, then a fragment per event, no client script                                                                                                                                                                  |

| Route               | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /`             | The prompt form; presets come from `GET /cf/v1/capabilities`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `POST /jobs`        | `sessions.create({ agent, environment: { type: "openai_hosted" }, input })`, then redirects to the job page. The subagents checkbox enables `multi_agent` so the preset may `cf_delegate` to its `delegates`                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `GET /jobs/:id`     | The job page. While the turn runs it opens the live SSE (`sessions.events.stream`), replays the durable log (`GET /cf/v1/sessions/:id/events?after=<seq>`) into the committed transcript, writes that, then keeps the response open and appends each later event as HTML: text deltas stream into the open block, every `item.done` is an item view, and the artifacts and zip link close the page when the session settles. A reload mid-turn repeats the replay and reattaches; nothing is lost. Once settled (`idle`, `failed`, or `requires_action`, which this demo cannot answer because it declares no function tools) it is one complete page |
| `GET /jobs/:id/zip` | Every `sessions.artifacts` entry, zipped                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## Run

The commands use pnpm; npm, yarn and bun work the same way with their own `install`, `exec` and `dlx` forms.

```sh
pnpm install
pnpm exec wrangler login   # Workers AI and deployments need your account
pnpm dev                   # Docker must be running; the first image build takes several minutes
```

Open <http://localhost:8787>. The app reaches the API over its Service Binding and names the tenant itself, so `API_TOKEN` in `.dev.vars` (32+ characters) only guards the HTTP API for outside callers. With rootless Docker use `pnpm dev:rootless` if `create-cf-open-agents-api init` added it.

Production: `pnpm dlx create-cf-open-agents-api@alpha setup` creates the R2 buckets and puts the secrets, then `pnpm exec wrangler deploy`.
