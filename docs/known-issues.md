# Known issues

Every entry is scoped to the pinned versions and the local suites. None is a blanket exemption for an error with a similar message elsewhere.

| Component                                  | Reproduction / scope                                                                                                                                                                                                                                                              | Treatment / removal condition                                                                                                                                                                                                                                        |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenCode `1.18.30`                         | Once a session stores a `json_schema` output format, listing that session's messages fails with a 500 because OpenCode cannot re-encode the stored format. Every structured turn would trip it.                                                                                   | The adapter never lists messages after a structured prompt. Usage and the settlement check read the event feed behind a session-metadata barrier instead. Recheck the message listing on OpenCode upgrade and remove the barrier when it works.                      |
| Rootless Docker                            | `pnpm test:containers` cannot reach workerd from inside the containers when Docker runs rootless with `--detach-netns`: the bridge lives in rootlesskit's network namespace.                                                                                                      | Run the smoke through the `nsenter` recipe in [deployment.md](deployment.md#local-runtime-notes). Rootful Docker needs nothing. Recheck when Wrangler's container emulation changes how it routes back to the host.                                                  |
| workerd `1.20260911.1`                     | Cancelling an SSE response after an SDK turn finishes can log `abortRead() has been called`.                                                                                                                                                                                      | API tests assert the complete turn and all streamed text before cancellation. Investigate any other occurrence; recheck on workerd upgrade.                                                                                                                          |
| Sandbox `0.13.0-next.751.1`                | Destroying a sandbox with a live `exec-server` process handle during the container restore smoke can report an RPC stub not disposed.                                                                                                                                             | The SDK's public `SandboxProcess` interface has no dispose method. The smoke explicitly destroys its containers; no private SDK fields are accessed. Recheck the process-handle lifecycle on SDK upgrade.                                                            |
| Containers local emulation                 | Wrangler prints FUSE, SYS_ADMIN and AppArmor privilege warnings.                                                                                                                                                                                                                  | These come from Cloudflare's Docker emulation, not production Worker privileges. Recheck when the SDK changes local backup requirements.                                                                                                                             |
| workerd `1.20260911.1` R2 emulation        | `pnpm test`, `tests/workers/io.test.ts`: deliberately ending a known-length producer early logs `fixed-length pipe ended prematurely` and `Network connection lost`.                                                                                                              | The test requires transfer rejection and verifies that no R2 object is published; the suite exits 0. Do not ignore these messages during successful transfers. Recheck on workerd upgrade.                                                                           |
| Worker Service Binding negative RPC tests  | `pnpm test`, `tests/workers/bindings.test.ts`: rejected tenant and page requests can also log that the Worker request had hung.                                                                                                                                                   | All six negative calls resolve to the asserted API error and the following valid call succeeds; the suite exits 0. Investigate any occurrence on a successful request; recheck with the next Workers test-pool or workerd upgrade.                                   |
| Workers RPC errors                         | `tests/workers/io.test.ts` intentionally requests a credential after an interrupted OAuth refresh and eviction; workerd logs `AgentApiError:409:outcome_unknown` as an RPC exception.                                                                                             | The caller asserts the exact 409 and then verifies recovery after manual rotation. This expected rejection does not exempt other RPC failures. Recheck when the RPC error transport changes.                                                                         |
| Sandbox `0.13.0-next.751.1` abandoned code | `pnpm test:containers`: the abandoned-workspace step destroys the sandbox while a `bash` process handle is live; the Wrangler log records `Uncaught Error: Programmatic tool call failed` and `StaleProcessHandleError: Process handle refers to a previous runtime incarnation`. | The smoke asserts the explicit `programmatic_execution_uncertain` outcome, revoked assignment and later restore, and exits 0. The messages belong to the deliberately interrupted call only; investigate any occurrence in a completed turn. Recheck on SDK upgrade. |
| pnpm `11.1.2` legacy deployment            | `pnpm deploy --prod --legacy` in `docker/Harness.Dockerfile` reports shared-lockfile and peer warnings while generating a filtered production tree.                                                                                                                               | The resulting tree passes `pnpm peers check` and the supervisor runs from it in the container smoke. Remove when migrating to pnpm's injected-workspace deployment.                                                                                                  |

A build alone does not establish that outbound callbacks or native WebSockets work; the container smoke does.
